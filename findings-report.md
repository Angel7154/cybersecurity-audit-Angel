# Findings Report

## Target Audited
Personal laptop

## Summary
I carried out a basic cybersecurity audit on my laptop to find out the security weakness and vulnerabilities it might have.

## Findings
1. The laptop has a faily strong password as it comprises only letters
2. The laptop Anti-Virus protection is on.
3. The firewall for domain network, private network and public network are on.
4. The Operating System has pending updates.
5. All the applications in the laptop are known and safe.
6. The permission to not install unknown application on the laptop is turned on.
7. Browser passwords are secure.
